# 0006. 명세 범위 조정: 원격 실행·Docker·Escher 제외, GUI 한국어화 중단

- 상태: 수락
- 날짜: 2026-09-29

## 맥락

명세 v3.0은 원격 서버/HPC 백엔드(FastAPI, 토큰), Docker Compose 실행, Escher 대사 지도(선택 기능), GUI 한/영 토글을 포함했다. 현재 CMIG는 로컬 데스크톱/CLI 도구로만 구현됐고, GUI 한국어 번역은 일부 화면(shell, 일부 편집기)에만 있다.

## 결정

- 원격 백엔드, Docker Compose, Escher 대사 지도는 계획 범위에서 제외한다.
- GUI 한국어화는 더 진행하지 않는다. 새 UI 문구는 영어로만 추가하고 한국어 번역 항목을 늘리지 않는다. 기존 `--lang ko` 경로는 그대로 둔다.
- 탐색 방법 확장(abundance 동시 최적화, synergy/null-model 목적, 자동 MIP/MRO 사전선별, Bayesian 탐색)은 계획 범위로 유지한다.

## 대안

- 명세 범위 전체 유지: 사용자가 원격·Docker·Escher를 더 만들 계획이 없다고 결정했다.
- 한국어화 완성: 사용자가 앞으로도 하지 않기로 결정했다.

## 결과

- 보안 정책은 로컬 단일 사용자 전제를 유지한다. 인증·토큰·네트워크 서버 표면이 없다.
- GUI의 한국어 모드는 영어가 섞인 부분 번역 상태로 남는다. 이는 결함으로 다루지 않는다.
- 명세서의 해당 절(§3 원격·Docker, §11 Escher·한/영 토글)은 개정되지 않은 문구로 남는다.
