# CMIG 0.2.0 changelog draft

This release-facing draft reorganizes the current `CHANGELOG.md` `[Unreleased]` block. It does not
replace that block and must be reconciled with concurrent round-7 entries immediately before the
release commit. Replace `YYYY-MM-DD` with the actual release date.

## [0.2.0] - YYYY-MM-DD

### Added

- Literature-grounded gut-medium overlays with row-level provenance, mirrored AGORA/VMH source
  data, a deterministic builder/checker, explicit anaerobic oxygen bounds, and pool-specific
  background-closure rows. The provenance records unit conversions and assumptions, and the test
  suite re-derives the shipped values.
- A Claude Code `cmig-metabolic-analysis` skill and installable plugin that route scientific intents
  to CLI workflows and enforce biomass-basis, interface-review, solver-provenance, medium,
  dFBA-sensitivity, exit-code, and artifact-integrity guardrails.
- Integrated publication preflight covering model quality, community solve, consortium search,
  dFBA sensitivity, host scale/mapping/coupling, checksums, acceptance fields, and artifact
  manifests.
- Annotation-aware host-interface mapping, objective-fixed transfer FVA intervals, mandatory
  microbial/host gDW basis provenance, and human-GEM acquisition/checksum records.
- A `result_digest` for workflow manifests, complementing the input-oriented `run_hash` with an
  artifact-byte fingerprint that `inspect-run` verifies.
- Cross-platform CI quality gates, workflow-envelope golden verification, distribution-content
  auditing, release/citation metadata, and pinned R/Bioconductor figure provenance.
- Scalable single-target consortium search using `--strategy ga`, automatic GA selection above the
  exhaustive threshold, seeded selection, evaluation/patience stops, and explicit population,
  mutation, immigrant, tournament, and elitism controls.

### Changed

- **BREAKING (scientific): boundary isolation now covers all COBRA boundary reactions—exchanges,
  sinks, and demands—not only `model.exchanges` or `model.medium`.** Host objectives,
  replacement-medium application, minimal-medium checks, and closed-uptake dFBA can therefore
  change. New non-hashed
  `boundary_isolation_policy` and `host_isolation_policy` markers date the answer; pre-marker runs
  on models with sinks/demands must be re-run.
- **BREAKING (scientific): custom media are translated by metabolite to exchange reactions.**
  Closed exchanges can now be opened, conflicting aliases are rejected, and the run records the
  medium policy. Older `--medium` runs can have different answers under an unchanged historical
  input hash and must be re-run.
- **BREAKING (scientific): host exchange resolution preserves BiGG id case**, including D/L
  stereochemistry, and host coupling closes undeclared background uptake by default.
- **BREAKING (scientific): maintenance and non-biomass objectives are no longer presented as
  growth.** Host summaries expose objective warnings and boundary counts; host commands propagate
  the same warning.
- Multi-target search reports jointly feasible vectors and documents the distinction between the
  N-dimensional Pareto mode and the two-target-only `pareto` column on scalar rankings.
- Weighted host ranking requires explicit positive reference scales so unlike units are normalized
  before combination; target-transfer is the default single metric.
- Run inspection now reports `status_source`, honest unknown/degraded/failed states,
  `artifact_integrity`, medium diagnostics, provenance markers, warnings, and the reason a digest
  is absent.

### Fixed

- `--allow-unknown-medium` is now available on `gene-ko-search`, `host-microbe-bigg`,
  `host-search-bigg`, and `host-ko-impact`, matching `solve`, `search`, `strain-growth`,
  `abundance-impact`, and `sweep`. Dropped ids are named, partial application is degraded, and the
  choice contributes to the applicable host run hash.
- `gene-ko-search` now accepts and records a community medium, applies it identically to baseline
  and knockout arms, ranks unevaluable rows separately, and offers explicit `effect` versus
  `remaining` ordering.
- Host-medium entries without a counterpart are no longer dropped silently, and failed community
  solves inside host workflows propagate their actual diagnostic.
- Failed strain-growth, sweep, gene-KO, and host-search computations no longer become measured
  zeros, ranked candidates, successful run statuses, or publication figure bars.
- Publication figures are included in workflow artifact declarations and therefore in
  `result_digest`; a mismatch reaches JSON/text status and exit code 3.
- Host-map behavior is fingerprinted from live matcher probes, host file paths no longer pollute
  content identity, and D/L stereoisomers survive id normalization.
- Workflow-envelope fixtures are built by production component builders and fail on fixture drift;
  shipped solver goldens now re-derive their stored hashes consistently.
- Community cross-feeding allocation conserves shared-pool supply and demand, model-directory
  discovery ignores adjacent provenance/analysis JSON, and deterministic sweeps do not invent
  p-values without confirmed independent replicates.

### Documentation

- Documented the complete CLI and answer-determining options, including multi-target metrics,
  `strain-growth --single-medium`, `abundance-impact --fva`, KO ordering, host KO impact,
  `--keep-host-uptake`, interface-map review, closed-uptake dFBA sensitivity, all exit codes, and
  both reproducibility fingerprints.
- Documented that the bundled microbial pool is a methods fixture rather than a representative gut
  community; the shipped legacy glucose presets are smoke fixtures, not citable diets.
- Corrected stale artifact lists, solver-selectability claims, Recon3D objective/load behavior,
  multi-target FVA limitations, publication-benchmark dFBA limitations, and edge-flux attribution.
