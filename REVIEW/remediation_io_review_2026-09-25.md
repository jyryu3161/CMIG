## Required correction: new Windows failure in the direct VMH/SBML branch (P2)

**Source:** `cmig/io/agora2.py:657–659`, newly calling `atomic_write_bytes`, reaches the pre-existing unconditional `os.fchmod(handle.fileno(), mode)` in `cmig/io/atomic.py:104`. Python 3.12 documents `os.fchmod` as available on Unix, not Windows ([official Python documentation](https://docs.python.org/3.12/library/os.html#os.fchmod)). `atomic_write_path` also contains the same pre-existing portability assumption; this review's regression is the newly affected direct-byte branch.

**Trigger:** a valid `CatalogueEntry('safe', 'safe.xml', '', '')`, ordinary writable output folder, `namespace='vmh'`, `file_format='sbml'`, and a successful fetch on Windows. There is no malicious input or solver dependency required. The download reaches temporary output creation and then raises `AttributeError: module 'os' has no attribute 'fchmod'` before publication.

**Independent reproduction:** `.run/remediation-20260925/io-review/probe_io.py` loads baseline `agora2.py` from Git into a separate module, obtains real minimal SBML through Cobra, and calls both baseline and current public `fetch_model` with the Unix-only API absent. Baseline succeeds; current raises the error above. Current previous output is preserved and staging is cleaned, so the safety correction succeeds but a previously functional platform branch stops producing any output. This is an API-absence emulation on macOS corroborated by the Python platform contract, **not a native Windows run**.

**Required regression and resolution:** make atomic publication work when the descriptor permission API is absent, while retaining atomic replacement, existing POSIX permission behavior, and failure cleanup. Add a public `fetch_model` regression for the successful VMH/SBML path under that platform capability and assert actual output bytes; retain failure-preservation coverage. A bounded shared-helper correction may also cover its other serializers. Do not return to non-atomic direct writes or mark the platform branch skipped. Sent immediately to the coordinator as escalation `msg_ccb6495fc0a4`; the coordinator acknowledged routing a Sol correction. No corrected implementation had been supplied for this review snapshot.
